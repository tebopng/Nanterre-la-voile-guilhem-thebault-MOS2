# Nanterre à la Voile

Site web de présentation d’un événement d’initiation à la voile et de handivoile sur voilier Hansa, du 9 au 13 juin 2027 à Boulogne-Billancourt.
Projet réalisé dans le cadre du Master STAPS Management des Organisations Sportives, Université Paris Nanterre.

## Pages

| Fichier | Contenu |
|---|---|
| `index.html` | Présentation de l’étudiant, de la formation et de l’université |
| `evenement.html` | Description de l’événement |
| `programme.html` | Programme et déroulé |
| `infos-pratiques.html` | Lieu, accès, matériel, accessibilité, tarifs |
| `inscription.html` | Formulaire d’inscription |

## Voir le site

Ouvrir `index.html` dans un navigateur, ou le publier avec GitHub Pages (Settings > Pages > branche `main`, dossier `/root`).

Le formulaire est un formulaire HTML simple, il n’est relié à aucun serveur.
